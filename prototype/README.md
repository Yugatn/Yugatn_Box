# Yugatn Box UI Prototype

Open `index.html` in a modern browser or publish this folder through a static web host to inspect the first console-dashboard mockup.

## Included

- Dark, controller-oriented console dashboard layout.
- Responsive layout for large displays and smaller screens.
- Demonstration library cards and filters.
- Navigation states for Home, Library, Devices, Compatibility, and Settings.
- Modal examples for game launch and phone pairing.
- Clear demo labels and explicit non-compatibility disclaimer.

## Not implemented

- No games are installed or launched.
- No connection to Steam, Xbox, PlayStation, Nintendo, cloud gaming, or any account.
- No real phone pairing, video streaming, controller input backend, or system settings.
- No actual compatibility testing has been performed.

This is a static interaction prototype to evaluate the product concept and interface. All game names and statuses are illustrative.
