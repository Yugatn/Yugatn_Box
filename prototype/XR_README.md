# Yugatn Box XR Hub Prototype

Static interaction mockup for the planned VR/AR/MR/XR subsystem.

## Includes
- Display-mode selector: TV/monitor, virtual screen, PC VR, AR/MR.
- Device discovery placeholder.
- XR settings toggles.
- Compatibility status labels.
- Explicit warning that support is not verified.

## Not implemented
- No headset discovery or runtime integration.
- No actual XR session, streaming, video routing or telemetry.
- No compatibility results or hardware tests.

All controls are illustrative UI only. See [XR support strategy](../docs/XR_SUPPORT.md) and [system architecture](../docs/ARCHITECTURE.md).
